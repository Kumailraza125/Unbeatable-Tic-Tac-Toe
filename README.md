An unbeatable Tic-Tac-Toe AI made using the Minimax algorithm. Players play against an AI that takes user input 
and then determines the most optimal counterplay against them. 

## FEATURES:
- Minimax AI: Uses recursive game-tree traversal to determine the best possible move 
- Dynamic Game Tree: Generates board states using a variety of C++ classes, pointers, and vectors.
- Input Validation: Prevents players from inputting incorrect moves (placing game tiles where tiles already exist)
- Game Logic: Determines who wins, loses, or if a draw occurs between players. 

## TECHNOLOGIES:
- C++
- Object-Oriented Programming
- Recursive and Minimax Algorithm
- STL Vectors

## HOW TO PLAY:
- Choose who starts player (x) or computer (o)
- Enter numbers 0-8 that correspond to the board positions
- Continue playing until someone wins
